# COM_WEB_004_CLAUDE_HOME_DESIGN_REVIEW

Status: PRIVATE_WORKING
Date: 2026-08-23
Venture: Tropik Commerce
Source: Founder screenshots of WordPress POC v0.2 + Claude Design Home POC output + founder feedback

## Objective
Decide what visual direction from the Claude Design Home study should drive WordPress POC v0.3.

## Founder feedback captured
- Current WordPress POC v0.2 is not visually attractive enough.
- Header/icons are visibly misaligned.
- Three adjacent category cards using different White / Ink / Sun surfaces feel inconsistent.
- Founder prefers Typography Direction C (Bricolage Grotesque + Lexend) with selective yellow/Sun details.
- Claude Design System has been created using the existing logo and selected older Instagram references.

## KEEP from Claude Home study
1. Image-led hero with large rounded editorial asset.
2. Compact centered-logo header.
3. Bricolage-led expressive headline hierarchy.
4. Sun CTA/button and micro-accent system.
5. Consistent category card family using imagery + restrained overlay.
6. Product grid with large image ratio and minimal metadata.
7. Split Our Story editorial block.
8. Compact trust/reassurance area.
9. Dark footer with clear shop/discover/help hierarchy.
10. Strong Ivory/White negative space.

## REFINE
1. Desktop header needs explicit SHOP affordance and aligned Search / Account / Cart hit areas.
2. Mobile drawer must be treated as a primary branded interaction, not default overlay chrome.
3. Category card family should share one visual treatment; product/category identity comes from imagery and content.
4. Product grid must later use real WooCommerce data rather than invented static data.
5. Region behavior should remain operationally simple and not be exposed with unvalidated copy.
6. Newsletter signup remains optional until email platform/process is validated.
7. Trust statements must be sourced from actual policy/product/payment configuration.

## REMOVE / REJECT from current WordPress v0.2
- flat full-Leaf hero as final Home solution;
- White/Ink/Sun adjacent category card backgrounds;
- vertically staggered header icons;
- large dead-space zones without purposeful imagery/content.

## AI-generated details that are placeholders only
Do NOT publish without validation:
- prices;
- product counts;
- scarcity/limited-drop language;
- return-window claims;
- fabric/material claims;
- fulfillment-region copy;
- payment-method claims;
- company legal-entity suffix;
- sustainability/carbon claims.

## v0.3 build target
Create a staging-only implementation that visually tests:
- aligned header;
- Typography C;
- image-led hero placeholder;
- consistent category cards;
- product-card visual system;
- editorial story block;
- neutral reassurance strip;
- refined footer;
- responsive behavior.

Do not connect invented prices/policies or modify production.

## Approval status

Business/policy copy inside Claude mockup: NOT APPROVED.
Production migration: RED.
