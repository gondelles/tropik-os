# COM_09_HOME_POC_BRIEF_v0.1

Status: PRIVATE_WORKING
Version: 0.1
Updated: 2026-08-22
Venture: Tropik Commerce

## Objective
Design the first high-fidelity responsive Home POC for Tropik before expanding implementation.

## Experience goals
- premium-accessible, modern and distinctive;
- warm tropical energy without cliché;
- exceptionally easy to shop;
- fast/mobile-first;
- strong centered Tropik logo;
- off-canvas/drawer navigation;
- clear path to purchase;
- rounded contemporary components;
- selective Sun-yellow details, not yellow everywhere.

## Typography — POC direction
Founder preference: Direction C / Expressive Optimist.
- Display: Bricolage Grotesque 700/800
- Body/UI: Lexend 300/400/500
- Use Bricolage mainly at display sizes; avoid making small UI playful/noisy.
- Use Lexend for navigation, product info, prices, body and controls.

## Working palette
- Ink #171717
- Ivory #F6F2E8
- Sun #F6B218
- Leaf #0F5A46
- White #FFFFFF
- Mist #ECEBE7

Sun use: badges, active states, primary CTA/detail accents; do not use low-contrast Sun body text on white.

## Required Home structure
1. Sticky Header
2. Editorial Hero
3. Shop by Category
4. Featured Drop / Product grid
5. Editorial brand/story section
6. Trust / reassurance strip
7. Footer

## Header
Desktop:
`[☰ SHOP]         [TROPIK LOGO]         [Search] [Account] [Cart]`

Mobile:
`[☰]              [TROPIK]              [Cart]`

Drawer should feel like a deliberate part of the brand rather than a default WordPress menu.

## Month-1 categories
LATAM: T-Shirts / Hoodies / Caps.
USA: T-Shirts / Hoodies / Caps / Posters.
Do not expose fulfillment mechanics as primary navigation.

## Visual direction
- large editorial composition;
- tactile/natural light imagery later;
- strong negative space;
- asymmetric detail where useful but disciplined grid overall;
- 24px rounded cards/images as working token;
- subtle motion/hover only;
- no large carousel/slider as the primary hero;
- no generic eco iconography;
- no palm-tree cliché;
- no fake product claims.

## Mockup outputs required before implementation expansion
1. Desktop Home — 1440px
2. Mobile Home — 390px
3. Desktop navigation drawer open
4. Mobile navigation drawer open

Use image placeholders for fidelity-sensitive product imagery until approved creative assets exist.

## Acceptance criteria
- user knows what Tropik sells within ~3 seconds;
- primary shopping CTA is obvious;
- typography C feels expressive but readable;
- Sun accent is memorable but restrained;
- hierarchy works at mobile width;
- no interaction requires a heavy plugin to reproduce;
- design can map to WordPress/WooCommerce blocks plus small controlled custom code where justified.
