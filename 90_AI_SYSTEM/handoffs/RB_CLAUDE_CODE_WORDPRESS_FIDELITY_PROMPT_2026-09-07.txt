8. CONTENT ZONES / ACCENT SEMANTICS
==================================================

Primary public pages should use at least four clear content/narrative zones where the page scope supports it.

Use only Golden Master-approved accent tokens.
Do not invent new hex values.
Do not create random rainbow cards.

Semantic accent guidance:
- Sun/Yellow = action, active state, progress, primary CTA, commerce action.
- Leaf/Green = recovery, materials, process, validated/positive operational progress.
- Coral = people, community, work, participation, warm urgency/support.
- Ivory/White = evidence, methodology, transparency, policy/neutral explanation.

Accent should usually appear as eyebrow/bullet, small border/rule, status detail, icon or CTA detail — not as arbitrary full-card background changes.

Equivalent cards keep the same base surface, radius, padding and typography regardless of accent.

==================================================
9. RAILS — MOBILE ONE-CARD RULE
==================================================

Delete the v2 rule that hides arrows on mobile.

For landing-page narrative/card rails:

Desktop:
- horizontal rail;
- multiple cards visible as Golden Master allows;
- left/right arrows vertically centered on rail edges.

Tablet:
- horizontal rail;
- swipe + arrows;
- no accidental clipping.

Mobile:
- ONE primary card visible at a time per rail;
- do NOT vertically stack card 2/3/4;
- left/right arrows visible and vertically centered at safe left/right rail edges;
- each arrow advances exactly one card;
- touch swipe may remain as secondary navigation;
- use scroll-snap/equivalent deterministic positioning;
- arrows never cover copy.

Exception:
Dedicated collection/catalog pages may use normal vertical product browsing/scrolling. The one-card rule is for narrative/landing-page rails.
