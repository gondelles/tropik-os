# 10_BUILD_IN_PUBLIC_POLICY

Status: PRIVATE_CANONICAL  
Version: 1.1

## Purpose

Capture the real construction of Tropik Goods as reusable professional content/IP without exposing sensitive information or turning content creation into a blocker.

## Capture useful events

- important decisions and rationale;
- before/after audits;
- mistakes and corrections;
- experiments;
- AI collaboration workflows;
- useful checklists/frameworks;
- WooCommerce relaunch lessons;
- product/course discovery lessons.

## Minimal log fields

Date / Venture / What happened / Evidence changed / Lesson / Public usefulness / Sensitivity / Possible format / Publication status.

## Publication states

- INTERNAL_ONLY
- SANITIZE_FIRST
- PUBLIC_CANDIDATE
- PUBLIC_APPROVED
- PUBLISHED

Only PUBLIC_APPROVED authorizes publication.

## Priority rule

**Execution creates content.** Default: capture the learning in 2–5 minutes, continue execution, repurpose later.

All public promotion follows `00_HQ/governance/11_PUBLICATION_POLICY.md`.
