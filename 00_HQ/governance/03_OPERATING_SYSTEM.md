# 03_OPERATING_SYSTEM

Status: PRIVATE_CANONICAL  
Version: 1.1

## Build sequence

**IDEA → ASSUMPTION → VALIDATION → DECISION → MANUAL PROCESS → SOP → AUTOMATION → SCALE**

Do not skip directly from idea to automation or scale.

## Priority system

- **GREEN:** execute now.
- **YELLOW:** prepare, validate, research or monitor.
- **RED:** do not execute yet.

Default portfolio WIP: maximum 3–5 active priorities.

## Decision dimensions

For meaningful work estimate:
- Impact: Low / Medium / High
- Urgency: Low / Medium / High
- Effort: Low / Medium / High
- Reversibility: Easy / Moderate / Hard
- Evidence: Weak / Medium / Strong

## Required execution block

For build/configure/launch/audit/automate/scale work use:
1. Objective
2. Expected result
3. Recommended tools
4. Concrete steps
5. Validation checklist
6. Approved / not-approved criterion
7. Risks and common errors
8. Recommended delegation
9. Next concrete action

## Artifact lifecycle

- `PRIVATE_CANONICAL` — approved source of truth.
- `PRIVATE_WORKING` — draft/research.
- `EXPERIMENT` — hypothesis/test.
- `PUBLIC_CANDIDATE` — sanitized publication candidate.
- `PUBLIC_APPROVED` — explicit human approval to publish.
- `ARCHIVED` — retained history, not current truth.

## Weekly CEO questions

- What moved?
- What is blocked?
- What evidence changed?
- Which decision is required?
- What should stop?
- What are the next top 3 priorities?
