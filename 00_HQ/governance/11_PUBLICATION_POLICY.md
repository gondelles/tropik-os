# 11_PUBLICATION_POLICY

Status: PRIVATE_CANONICAL  
Version: 1.0

## Core rule

**Private by default. Public only by explicit promotion.**

`gondelles/tropik-os` is canonical private infrastructure and must remain private. Do not make this repository public to showcase work.

## Publication flow

```text
PRIVATE_CANONICAL / PRIVATE_WORKING
        ↓
select useful learning/artifact
        ↓
sanitize and generalize
        ↓
PUBLIC_CANDIDATE
        ↓
privacy / security / commercial review
        ↓
HUMAN APPROVAL
        ↓
PUBLIC_APPROVED
        ↓
copy to a separate public portfolio surface
```

## Public artifacts must be derivatives

Never mirror internal canonical files wholesale.

A public artifact should disclose only what demonstrates skill/value, for example:
- problem and constraints;
- sanitized architecture;
- non-sensitive implementation approach;
- tools/skills;
- validation method;
- safe results;
- reusable templates created specifically for publication;
- lessons learned.

## Must remove or avoid

- credentials/secrets;
- private customer/client data;
- sensitive supplier terms;
- exact internal economics if commercially harmful;
- private URLs/system details that increase attack surface;
- unresolved vulnerabilities;
- tax/legal assumptions;
- internal disagreements or strategy that weakens negotiation/competitive position.

## Standard public case-study structure

1. Executive Summary
2. Problem
3. Constraints
4. My Role
5. Architecture
6. Approach
7. Implementation
8. AI Workflow
9. Validation
10. Results (safe)
11. Tech Stack

14. What I Would Improve
15. Public Artifacts
16. Privacy Note

## Target outcome

Public work should strengthen the founder's professional visibility and demonstrate applied skills in AI orchestration, project/product operations, automation, data, e-commerce and systems thinking without exposing Tropik Goods' sensitive source of truth.
