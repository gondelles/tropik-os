## Local standards desk research

### VERIFIED FACT — COVENIN 2000:1987 / road specifications
The Venezuelan road specification for natural and mixed granzón establishes, among other requirements, gradation envelopes, liquid/plastic limits, CBR and written Ministry approval. For natural granzón: base LL ≤25%, PI ≤6%; base CBR ≥80% for heavy traffic and ≥60% for light traffic; compacted natural granzón reaches 95% of laboratory maximum dry density using modified Proctor as the reference method.

For crushed-stone base, the specification requires clean hard/resistant material, Los Angeles-type wear under COVENIN 266 ≤50%, fractured faces per COVENIN 1124, LL ≤25%, PI ≤6%, defined Type 1/2/3 gradations and CBR ≥80%, with prior written Ministry approval.

**Interpretation:** useful Venezuelan benchmark for Road Base trials; it does not expressly approve recycled C&D aggregate.

### VERIFIED FACT — Venezuelan aggregate/lab ecosystem
COVENIN aggregate methods remain discoverable through SENCAMER/FONDONORMA references; Venezuelan labs publicly advertise granulometry, Proctor, CBR, density and aggregate testing to COVENIN/ASTM methods. Exact lab competence/accreditation, methods, turnaround and quote are FIELD VALIDATION REQUIRED.

### Foreign reference
FHWA/ASTM/AASHTO and other recycled-aggregate standards are benchmark tools only when a local/project specification is silent. They are not automatic Venezuelan approval.

## 1. RB-RB-040 — Re:Build Road Base 0–40

**Intended application:** approved non-structural road base/subbase/temporary access-road layer.  
**Prohibited:** structural concrete; drainage-sensitive layer without chemistry/fines review; public road use without project/authority approval.

**Target trial envelope — WORKING HYPOTHESIS:**
- nominal top size: 40 mm target product name; buyer may require another envelope;
- sieve/gradation: first compare to COVENIN 2000 project-appropriate granzón/piedra-picada envelope;
- LL ≤25%, PI ≤6% if treated as base benchmark;
- CBR: ≥80% heavy-traffic benchmark; ≥60% light-traffic only where the approving engineer/spec allows;
- field compacted density: target ≥95% modified-Proctor MDD where applicable;
- abrasion: COVENIN 266 benchmark ≤50% for relevant base aggregate;
- visual/physical contamination: no hazardous material; organic/wood/plastic/gypsum/glass limits **BUYER/ENGINEER TBD**;
- moisture: controlled around project OMC for placement; sale moisture limit **TBD**;
- chemistry: chlorides/sulphates/pH/leachate only as source/use risk requires; drainage/tufa risk to be reviewed for RCA.

**Minimum first qualification:** gradation + Atterberg + Modified Proctor + CBR + abrasion + absorption/specific gravity + contamination composition; add sulphate/chloride/leachate where source/use indicates.

**Sampling:** each trial batch; after process stability, engineer/buyer to approve frequency. Proposed initial release lot ≤250 t until variability known.

**Batch release:** PASS only if source traceable, prohibited contaminants absent, required test limits met and buyer/project engineer signs accepted trial specification.

## 2. RB-MF-GEN — Re:Build Mineral Fill

**Intended:** non-structural backfill, grading, terracing or engineered fill only under a project-specific fill specification.  
**Prohibited:** structural bearing claim, uncontrolled coastal fill/dumping, drainage use without suitability review.

**LOCAL ENGINEERING SPECIFICATION TBD.**

Minimum tests: gradation/fines; Atterberg if fines are plastic; moisture-density/Modified Proctor; field density on placed trial; contamination; organic content if suspect; sulphate/chloride/leachate where receptor/source requires. CBR only where bearing function is specified.

Initial target: ≥95% MDD where the project engineer adopts the COVENIN road/earthwork benchmark; exact field lift thickness and moisture window are project-specific.

## 3. RB-MA-025 — Re:Build Masonry Aggregate

**Intended:** approved non-structural base/fill/landscape or civil works after variability testing.  
**Prohibited:** structural concrete aggregate by default; unverified drainage layer.

Minimum tests: gradation, fines/plasticity, water absorption/specific gravity, abrasion/durability/soundness where applicable, compaction/CBR where load-bearing, contamination and source variability. Masonry-rich material is expected to have higher absorption/variability than concrete-rich RCA; exact acceptance limits are **BUYER/ENGINEER TBD**.

Initial lot cap: 100–200 t until 3 consecutive source/batches show consistent results.

## 4. RB-FE-SCRAP — Re:Build Ferrous Scrap

**Intended:** authorized recycler/steel-processor feedstock.  
**Prohibited:** direct structural reuse as reinforcement; uncontrolled torch cutting/hot work; contaminated sealed vessels.

Buyer specification governs: grade/size, non-ferrous contamination, concrete attachment, oil/chemical contamination, maximum piece dimensions, radiation check if buyer requires, loading/bundling and title/chain-of-custody. No generic COVENIN construction grade claim is made.

Release: weighed lot + photos + source/batch linkage + buyer acceptance rules + safe dispatch.

## 5. RB-REUSE-VER — Verified Reuse Components

**Intended:** individually approved second use; non-structural by default.  
**Prohibited:** blanket structural/life-safety reuse; electrical, pressure, lifting, fire-rated or structural components without competent inspection/testing for the exact intended use.

Record each item: unique ID, source, photos, dimensions, visible damage, contamination, prior function, cleaning, assessor, approved intended use, prohibited use, recipient, chain-of-custody. Structural/rebar/critical-component reuse remains RED without engineer approval.

## Specialist gates
- Materials/pavement engineer: final local/project specification and release limits.
- Credible/accredited laboratory: methods and results.
- Environmental specialist: chemistry/leachate/drainage risk where relevant.
- Venezuelan counsel/authority: legal classification and required approvals.

## Major implementation block
**Objective:** turn five product concepts into testable buyer specifications.  
**Expected result:** at least Road Base or Mineral Fill plus Ferrous Scrap reaches an accepted controlled trial.  
**Recommended tools:** local project specification, COVENIN methods, lab chain-of-custody, batch register, buyer technical sign-off.  
**Concrete steps:** obtain buyer spec -> agree test plan -> make traceable trial batch -> test -> issue HOLD/PASS -> field trial -> record acceptance.  
**Validation checklist:** source traceable; test method/limit agreed; prohibited use explicit; lab report; buyer acceptance; environmental gate.  
**Approved:** written technical acceptance for a bounded trial/use.  
**Not approved:** marketing/product page states compliance before buyer/engineer/authority validation.  
**Risks:** using virgin-aggregate specs as automatic RCA approval; inconsistent source; hidden gypsum/wood/asbestos; high absorption/fines; testing after delivery.  
**Delegation:** materials/pavement engineer + laboratory + environmental/HSE specialist.
