# 1. Conceptual 1-ha geometry

**WORKING HYPOTHESIS:** conceptual site rectangle = **100 m x 100 m**. Final geometry must follow surveyed boundaries, drainage, prevailing wind, setbacks and host-site rules.

Flow concept:

`SOUTH / CONTROLLED ENTRY -> WEIGH + PHOTO -> INSPECTION/TIPPING -> SORT/RECOVERY -> MINERAL FEED -> CRUSH -> MAGNET -> SCREEN -> QA -> FINISHED STOCK -> DISPATCH -> EXIT`

Truck movement should be one-way wherever practicable. Pedestrian routes must be physically separated from mobile plant. Quarantine, sensitive-item recovery and residuals sit outside the normal mineral-processing path.

## 4. Process engineering

### 4.1 Normal flow
1. Dispatch authorization.
2. Gate/security check.
3. Gross/axle weight + source ticket + photographs.
4. Visual safety inspection.
5. Controlled tipping.
6. Gross sorting: reuse / metal / clean concrete / masonry / clean wood / other / residual / suspect.
7. Oversize reduction only as required for crusher feed.
8. Jaw crushing.
9. Magnetic separation.
10. Screening to defined product gradations.
11. Sampling / QA / batch hold.
12. Product release.
13. Dispatch loading + outbound weight + destination record.

### 4.2 Contaminated-load exception
`STOP -> isolate vehicle/load -> HSE review -> photograph + record -> quarantine or reject -> specialist pathway -> vehicle/site decontamination if required -> incident closeout.`

No suspect load may be blended into normal stockpiles.

### 4.3 Reusable-item flow
`identify -> isolate -> photo/tag -> sensitive-item check -> condition/safety assessment -> approved reuse inventory -> recipient/buyer -> chain-of-custody record.`

**PROHIBITED CLAIM:** recovered structural elements are not structural-grade unless a qualified engineer and applicable tests/specifications approve the exact element/use.

### 4.4 Hazardous / suspect-material flow
`visual trigger -> exclusion -> quarantine -> specialist identification -> authorized removal/disposal.` Re:Build does not treat hazardous material.

### 4.5 Residual-disposal flow
`sort reject -> weigh/estimate -> contained residual bay -> dispatch ticket -> authorized final disposal -> receipt/closure record.`

## 6. Equipment configurations

### Scenario 1 — Ultra-Lean MVP
**STRATEGIC DECISION:** maximize host/public/in-kind equipment. Re:Build cash-purchases only portable HSE, bins, traceability, basic QA and weighing where not already available.

Core shared/in-kind: loader, excavator, breaker, crusher, screen, magnet, trucks, water bowser.  
Core cash/portable: PPE, barriers, skips, office/welfare, camera/data, portable scale if needed, sample tools, spill/fire/first-aid kits.

### Scenario 2 — Controlled MVP
Dedicated/rented loader + excavator + mobile jaw crusher + mobile screen; integrated magnet; portable scale; water bowser/mist; basic workshop and office. This is the preferred costing case if shared machinery cannot guarantee uptime.

### Scenario 3 — Expansion Facility
At ~150–300 t/day sustained: dedicated processing train, second loader or skid steer, conveyors/picking belt only if measured sorting bottleneck warrants it, fixed weighbridge, expanded QA/storage. Progressive ownership may be evaluated only after utilization, downtime and payback are measured.

**RED:** purchasing heavy plant before pilot evidence.

## 11. Storage logic

**WORKING HYPOTHESIS:** with safe pile geometry confirmed by engineer, 750 m² of finished-product space at ~3 m nominal pile height, ~60% volumetric utilization and ~1.6 t/m³ bulk density is roughly a **2,160 t gross theoretical envelope**. Actual usable capacity must be reduced for product separation, loader access, drainage and pile-slope safety.

Operational TARGET: incoming mixed material dwell <3 days where practicable; released product dwell <7–14 days. At 300 t/day, 1 ha becomes increasingly dependent on very fast outbound movement; hence 2–3 ha expansion footprint.

## 12. Product/QA gates

No mineral product is released without: source/batch traceability; contamination check; defined gradation; moisture/compaction or other application-specific testing; buyer/engineer acceptance criteria; local engineering specification TBD where no confirmed Venezuelan standard has been mapped.

Reference tests to evaluate with the Venezuelan materials engineer/lab include sieve analysis/gradation, plasticity where fines matter, Proctor/moisture-density, CBR for base/fill applications, abrasion/durability and chemistry/leachate where source/use indicates risk. Do not copy foreign standards directly into public product claims without local review.

## 13. Site GO / HOLD / REDESIGN gate

### GREEN / GO to controlled physical pilot only if
- written site authorization;
- authorized debris routing;
- material ownership/use rights documented;
- HSE/environment procedure approved by qualified local specialist;
- hazardous/suspect off-site pathway documented;
- loader/excavator/crusher/screen availability documented or host train formally accessible;
- calibrated/defensible weighing method;
- at least one mineral product test protocol;
- at least one buyer/reconstruction project agrees to evaluate sample material;
- funded payroll/PPE/operating budget for the pilot window.

### YELLOW / HOLD
A site exists but one or more fatal dependencies above remain unresolved.

### RED / REDESIGN
Re:Build would need to buy major plant to learn, lacks legal site/feedstock/output rights, cannot safely control hazardous material, or has no credible product/use pathway.
