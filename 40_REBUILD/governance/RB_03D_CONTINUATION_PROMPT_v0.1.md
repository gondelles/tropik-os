# 1. RB-03D PURPOSE

RB-03D is an **evidence-ingestion and decision-reconstruction session**.

Do not create another speculative layer over RB-03C.

The purpose is to take whatever real evidence has now been obtained from Santa, field visits, authorities, buyers, labs, recyclers, vendors, engineers, crews and potential funding/resource partners and use it to determine:

`WHAT IS NOW VERIFIED -> WHAT ASSUMPTION IT REPLACES -> WHAT CHANGED -> WHAT REMAINS FATAL -> WHAT THE PILOT NOW COSTS -> WHETHER WE GO / HOLD / PIVOT / STOP`

If some evidence has not yet arrived, do not stall. Identify the exact missing document/person/measurement and keep the affected decision open.

---

# 2. MANDATORY CLASSIFICATION

Every material claim must be classified as:

- **VERIFIED FACT**
- **STRATEGIC DECISION**
- **WORKING HYPOTHESIS**
- **TARGET**
- **ASPIRATION**
- **PROHIBITED CLAIM**

Use:

> ⚠️ **WORKING HYPOTHESIS — FIELD VALIDATION REQUIRED:** This figure/condition is a planning approximation. It is not a measurement, authorization, quote or confirmed site condition.

For capital/legal/HSE/environment/product/funding-sensitive items also state:

> **DO NOT USE AS PUBLIC FACT OR CAPITAL COMMITMENT UNTIL VALIDATED.**

Never upgrade an interview statement into written authority, a quote into a commitment, an EOI into offtake, or a self-reported capability into verified availability.

# 12. WORKSTREAM I — GO / HOLD / PIVOT / STOP

Build a formal pilot decision gate.

## GO only if
- valid site authority;
- usable controlled polygon;
- routing/feedstock path;
- output rights;
- HSE/environment controls;
- hazardous/residual route;
- viable weighing/data chain;
- equipment/logistics plan;
- workforce plan;
- real lab path;
- real first-product trial path;
- buyer/project technical approver;
- 90-day cash/in-kind/payer/funding plan with sufficient working capital;
- founder approval for commitments.

## HOLD
Use when a finite set of evidence/agreements can reasonably close remaining gates.

## PIVOT
Use when Santa/product/buyer/operating architecture should be replaced by a better evidenced alternative.

## STOP
Use when fatal legal/HSE/economic/feedstock/offtake conditions make the current pilot thesis unacceptable.

Do not use optimism as a decision criterion.
